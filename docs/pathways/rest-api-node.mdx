## Overview
The REST API Node is a powerful component of the Pathlit workflow builder that allows you to interact with external REST APIs. It enables you to fetch data from or send data to any RESTful service, making it a versatile tool for integrating third-party services into your workflows.

## Configuration Parameters

To set up the REST API Node, you need to configure the following parameters:

* **Endpoint URL**:

    The URL of the REST API endpoint you wish to interact with. Ensure that the URL is correct and accessible from your network environment.

* **HTTP Method**:

    The HTTP method to use for the request, such as GET, POST, PUT, DELETE, etc., depending on the API's requirements.

* **Headers**:

    Optional HTTP headers to include in the request, such as authentication tokens or content types.

    <Tip>
    Ensure that any required authentication tokens are kept secure and not hard-coded directly into the workflow.
    </Tip>

* **Request Body**:

    For methods like POST or PUT, specify the request body in JSON format. This should align with the API's expected input.

## Expected Inputs and Outputs
- **Inputs**:

  - This node can accept dynamic input data to populate request parameters or body content, enabling flexible API interactions.

- **Outputs**:

  - The node outputs the response from the API call, which can be used by subsequent nodes in your workflow. The response is typically in JSON format and may require parsing to extract specific data.

## Use Case Examples
1. **Data Retrieval**:

    Use the REST API Node to fetch data from a remote service, such as retrieving weather data from a public API to trigger weather-related workflows.

2. **Data Submission**:

    Automate the submission of data to an external service, such as sending form responses to a CRM system via an API.

3. **Service Integration**:

    Integrate with third-party services, such as triggering a build in a CI/CD pipeline or posting messages to a social media platform.

## Error Handling and Troubleshooting
- **Invalid URL or Method**:

    Ensure that the endpoint URL is correct and that the chosen HTTP method is supported by the API.

- **Authentication Failures**:

    Verify that authentication tokens are correctly configured and have the necessary permissions for the API actions.

- **Response Errors**:

    If the API returns an error, check the response details to diagnose the issue, such as incorrect parameters or server errors.

If you encounter any issues with the REST API Node that are not covered in this documentation, please reach out to our [support team](mailto:dev@pathlit.ai) for assistance.
