## Overview
The Document Data Node is a powerful tool within the Pathlit workflow builder that allows users to extract and process data from various document formats. This node is designed to facilitate the automation of data extraction tasks, enabling seamless integration of document data into your workflows.

## Configuration Parameters

To configure the Document Data Node, you need to provide the following parameters:

* **Document Path**:

    Specify the path to the document file from which data will be extracted. The node supports a variety of document formats, including PDF, DOCX, and TXT.

* **Data Extraction Method**:

    Choose the method for extracting data from the document. Options include text extraction, table extraction, and metadata extraction. Select the method that aligns with your workflow requirements.

## Expected Inputs and Outputs
- **Inputs**:

  - This node requires a file input, which can be provided by other nodes in the workflow that handle file uploads or document retrieval.

- **Outputs**:

  - The node outputs extracted data in a structured format, which can be used in subsequent workflow steps. Outputs include:
    - **Extracted Text**: The full text content of the document.
    - **Extracted Tables**: Any tables found within the document, formatted as a list of dictionaries.
    - **Metadata**: Information about the document, such as author, creation date, and file size.

## Use Case Examples
1. **Contract Analysis**:

    Use the Document Data Node to extract key clauses from legal contracts. This can automate the review process and ensure compliance with contract terms.

2. **Invoice Processing**:

    Automate the extraction of invoice details, such as vendor, amount, and due date, to streamline accounting workflows and reduce manual data entry.

3. **Research Data Compilation**:

    Aggregate data from multiple research papers by extracting relevant sections and compiling them into a centralized database for analysis.

## Error Handling and Troubleshooting
- **File Not Found**:

    Ensure that the specified document path is correct and that the file is accessible. Verify the file format is supported by the node.

- **Extraction Errors**:

    If data extraction fails, review the document to ensure it is not corrupted and that the chosen extraction method is appropriate for the document's content.

If you encounter any issues with the Document Data Node that are not covered in this documentation, please reach out to our [support team](mailto:dev@pathlit.ai) for assistance.
