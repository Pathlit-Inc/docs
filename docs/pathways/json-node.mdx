## Overview
The JSON Node in Pathlit is designed to parse a JSON object and extract specified fields, making it easier to handle structured data within your workflows. This node is particularly useful for workflows that require processing JSON data from various sources, enabling you to extract and utilize specific information efficiently.

## Configuration Parameters

To configure the JSON Node, you need to define the following parameters:

* **JSON Input**:

    Enter a valid JSON object in this field. The node will parse this JSON to extract the specified fields.

    <Tip>
    Ensure that the JSON input is correctly formatted to avoid parsing errors.
    </Tip>

* **Expected Fields**:

    Specify the fields you expect to extract from the JSON object. These fields will be dynamically created as output ports, allowing you to use the extracted data in subsequent nodes.

## Expected Inputs and Outputs

- **Inputs**:

  - This node accepts input data through a specified input port, which can be used for templating the JSON input.

- **Outputs**:

  - The node outputs the specified fields from the JSON object. If a field is not found, a warning will be logged, and an empty string will be returned for that field.

## Use Case Examples

1. **API Response Parsing**:

    When working with APIs that return JSON data, use the JSON Node to extract relevant information, such as user details or transaction records, for further processing in your workflow.

2. **Data Transformation**:

    Transform and route data from JSON files for data processing tasks. Extract specific fields that need to be processed or analyzed separately.

3. **Integration with Webhooks**:

    Extract specific fields from JSON payloads received via webhooks. This allows you to automate actions based on the content of the webhook data.

## Error Handling and Troubleshooting

- **Invalid JSON Input**:

    If the JSON input is invalid, the node will raise an error. Ensure that the JSON is properly formatted and valid.

- **Field Not Found**:

    If a specified field is not found in the JSON object, a warning will be logged, and an empty string will be returned for that field. Double-check the field names in the JSON input and the Expected Fields configuration.

If you encounter any issues with the JSON Node that are not covered in this documentation, please reach out to our [support team](mailto:dev@pathlit.ai) for assistance.
