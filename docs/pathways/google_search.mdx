# Google Search Node

## Overview
The Google Search node allows you to perform searches using Google's search engine.

## Configuration

### GoogleSearchConfig
- **date_range**: Specifies the date range for the search. This field now uses an Enum to provide a structured way to specify date ranges.

## Usage
To use the Google Search node, configure the `GoogleSearchConfig` with the desired parameters, including the `date_range` using the provided Enum options.
