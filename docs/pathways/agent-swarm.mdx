## Overview
The Agent Swarm Node is a powerful component of the Pathlit workflow builder, designed to utilize multiple agents working in tandem to achieve complex tasks. This node allows you to specify a query and a set of agents that will collaborate and communicate to provide a comprehensive solution.

## Configuration Parameters

To set up the Agent Swarm Node, you need to configure the following parameters:

* **Query**:

    The task or question you want the swarm of agents to address. This could be anything from conducting a market analysis to solving a technical problem.

    Example:
    ```
    Provide up-to-date market analysis of the AI industry.
    ```

* **Agents**:

    A list of agents that will be part of the swarm. Each agent can be configured to perform specific roles within the swarm, and you can designate an initial agent to start the process.

* **Max Steps**:

    The maximum number of steps the swarm can take to complete the task. This controls the depth of the analysis and ensures that the process remains efficient.

    <Tip>
    Adjust the number of steps according to the complexity of the task. More complex tasks may require more steps.
    </Tip>

### Advanced Settings

Advanced settings panel can be expanded by clicking on the settings button on the top right corner of the node. The following additional configurations are available:

* **Max Steps**:

    This setting also appears in the main configuration but can be adjusted here for quick access.

## Expected Inputs and Outputs
- **Inputs**:

  - The node accepts input data through a specified input port, which can be any data relevant to the task the agents need to perform.

- **Outputs**:

  - **Output**: The final result from the agents after completing the task.
  - **Conversation**: A formatted log of the conversation and interactions between the agents during the task execution.

## Use Case Examples
1. **Market Research**:

    Use the Agent Swarm Node to gather and analyze data from multiple sources, providing a comprehensive market analysis report.

2. **Problem Solving**:

    Employ a team of agents to tackle complex problems by breaking them down into smaller tasks, allowing each agent to contribute its expertise.

3. **Collaborative Content Creation**:

    For content that requires input from multiple experts, this node can coordinate the creation process, ensuring that each section is handled by the most suitable agent.

## Error Handling and Troubleshooting
- **No Agents Provided**:

    If no agents are specified in the configuration, the node will raise an error. Ensure that you have added and configured at least one agent.

- **Invalid Agent Node**:

    If an agent node is not recognized, the node will raise an error. Make sure all agent nodes are correctly defined and available in your setup.

If you encounter any issues with the Agent Swarm Node that are not covered in this documentation, please reach out to our [support team](mailto:dev@pathlit.ai) for assistance.
