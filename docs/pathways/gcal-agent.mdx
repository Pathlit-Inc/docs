# GCal Agent Node

The `gcal_agent` node is a newly added feature that allows integration with Google Calendar. This node can be used to automate workflows involving calendar events, such as creating, updating, or deleting events.

## Features
- **Create Events**: Automatically create calendar events based on workflow triggers.
- **Update Events**: Modify existing events with new details.
- **Delete Events**: Remove events from your calendar as part of a workflow.

## Usage
To use the `gcal_agent` node, ensure it is properly configured in your workflow. You can specify the event details and actions to be performed when the node is triggered.

## Configuration
- **API Key**: Ensure you have a valid Google API key with access to the Calendar API.
- **Event Details**: Define the event parameters such as title, time, and participants.

This node is part of the Pathlit low-code workflow builder, designed to streamline calendar management tasks.
